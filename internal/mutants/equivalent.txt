# Mutants declared equivalent, one per line:
#   file | function | source line, trimmed | token -> replacement | why the behavior cannot change
# The tool matches on file, function and source text (not the line number) and reports these
# separately from real survivors. A declared mutant that the tests kill fails the run, so a wrong
# declaration cannot hide.
#
# Two facts carry most of the arguments below:
#   F1 (two exact paths). Each *Dir function returns the sign of (exact - r) either from an
#      error-free transformation or from an exact math/big comparison (106-bit products, or a
#      2200-bit sum, compared with r). Both give the exact sign whenever the error-free path's
#      preconditions hold: TwoSum is exact for finite operands whose sum does not overflow
#      (Knuth, TAOCP 4.2.2, theorem B); the FMA product error is exact when e_a + e_b >= -970
#      (Boldo and Muller 2011), implied by |r| >= 2^-900; the FMA division remainder and square
#      root residual are exact without underflow (Bohlender et al. 1991), implied by the 2^-900
#      and 2^1000 guards. A mutant that moves a guard by one comparison (< to <=, >= to >) only
#      changes which exact path handles the single value 2^-900 or 2^1000, where both preconditions
#      hold, so r and the sign are the same.
#   F2 (infinite operands). Without its infinity check, an infinite operand of addDir or mulDir
#      reaches "if math.IsInf(r, 0) { return r, -sign(r) }". rd(+Inf, -1) is MaxFloat64 and
#      ru(-Inf, +1) is -MaxFloat64, so the result differs from the exact path only if a caller asks
#      for a lower bound that is +Inf or an upper bound that is -Inf. No caller does: Add, Sub, Mul
#      and Div compute lower bounds from (Lo, Lo), (Lo, -Hi) or table entries whose exact value is
#      never +Inf, because a well-formed Lo is never +Inf and the tables pair signs so that a
#      lower-bound product or quotient of an infinity is -Inf; powDown is only called on Mig() and
#      on -Hi, which are finite for a non-empty interval. The 0 * Inf rule is checked before
#      these lines and is not affected.
